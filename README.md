# GLua Bounty System

## Features
### Ingame bounty hunter system that allows for players to set bounties on others and for the set bounty hunter jobs to track the targets and claim rewards
- Full external config
  -   Bounty Hunter teams/jobs
  -   Excluded teams/jobs
  -   Rewards for completion
  -   Maximum reward players can set
- Bounty Terminal for players to set bounties
- Bounty Board for players to view current bounties
